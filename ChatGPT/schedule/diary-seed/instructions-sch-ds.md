# 目的

毎日19:00に、翌日分の「日記」と「豆日記」の種ファイルを作成する。

# 実行条件

- 毎日19:00に実行する。
- 日付の判定は `Asia/Tokyo` を基準とする。
- 作成対象日は、実行日の翌日とする。
- 年末・月末を含め、年・月・日・曜日はすべて作成対象日から算出する。

# 日付表記

作成対象日の各値を次の形式で使用する。

- `YYYY`: 4桁の年
- `MM`: 2桁の月
- `DD`: 2桁の日
- `Ddd`: 英語3文字の曜日。先頭のみ大文字とする。
  - `Mon`
  - `Tue`
  - `Wed`
  - `Thu`
  - `Fri`
  - `Sat`
  - `Sun`

# 作成するファイル

## 日記

次のパスにファイルを作成する。

`Dropbox\scribe\writing\日記\<YYYY>\<MM>\<YYYY>-<MM>-<DD> <Ddd>.md`

内容は次のとおりとする。

```markdown
# 寝起き


```

## 豆日記

次のパスにファイルを作成する。

`Dropbox\scribe\writing\豆日記\<YYYY>\<MM>\<YYYY>-<MM>-<DD>.md`

内容は次のとおりとする。

```text
豆日記 <YYYY>-<MM>-<DD>


```

`<YYYY>`、`<MM>`、`<DD>` は作成対象日の値に置き換える。

# 作業手順

1. `Asia/Tokyo` の実行日を確認し、その翌日を作成対象日とする。
2. 作成対象日から `YYYY`、`MM`、`DD`、`Ddd` を生成する。
3. 必要な年・月フォルダが存在しない場合は作成する。
4. 日記ファイルと豆日記ファイルについて、それぞれ既存ファイルの有無を確認する。
5. 存在しないファイルだけを指定された内容で作成する。
6. 既存ファイルは内容にかかわらず上書きしない。
7. 一方の作成に失敗しても、もう一方が作成可能なら処理を続行する。

# 完了時の報告

処理後、次だけを簡潔に報告する。

- 作成したファイル
- 既存のため作成しなかったファイル
- 作成に失敗したファイルと、その理由

対象外のファイルは変更しない。
