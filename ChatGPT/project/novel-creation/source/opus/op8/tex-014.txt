# 冒険者ギルド
　ウスターシュの魔法屋を出たギルたちは、その足で冒険者ギルドへ向かった。冒険者ギルドについては、街道で助けたモルガンからいろいろと聞かされている。
　旅を続けるなら加入していて損はないとのことだ。魔物素材の買い取りをしていることや、周辺地域の情報を提供してくれることが役立つという。

　さて、ギルたちが出掛けに聞いておいたその場所は大通りに面していて、宿屋からまっすぐ向かわなくても簡単に見つけることができた。建物が大きく、抱えるほどの石で作られた立派なものだったことも迷わないで済んだ一因であろう。
　中に入るとまず天井が高いことに驚かされる。その天井近くには魔照具が｜幾《いく》つも掲げられ、光が｜煌々《こうこう》と降り注いでいて室内には十分な明るさがあった。
　入って正面の奥には受付カウンター、片側は食堂になっていて反対側には｜沢山《たくさん》の紙が張り出されている。そこかしこにいる冒険者たちは様々に武装していて、プレートアーマーを着込んだ重装備の者や、革の部分鎧の上にローブを羽織った魔法師らしき者たちもいた。魔法的防御が為されているだろう露出の多いバトルドレスを｜纏《まと》った女戦士は、伝承のヴァルキュリアのようにも見える。そんな中をギルたちは物珍しそうに見回しながら受付カウンターに向かった。

「いらっしゃいませ」

　｜揃《そろ》いの制服に身を包んだ若い女の担当者たちが待ち受ける窓口の一つへ行くと、色白で見目麗しい職員が柔らかな微笑みを｜湛《たた》えて迎えてくれ、ギルも軽く笑みを作って用件を告げる。

「冒険者ギルドに加入したいと思ってるんだけど、その前に改めて確認しておきたいことがあるんだ。いいかな？」
「はい、結構です。どのようなことでしょう？」

　通常業務のことらしく、少しギルに｜見惚《みと》れながらも職員は、笑顔を崩さぬままごく自然に応対した。ギルはモルガンから聞いたことを念頭にして、簡単に尋ねる。

「旅をするのに便利な便宜を図ってくれるって聞いたんだけど、具体的にはどんなことなの？」
「はい、冒険者ギルドでは旅をされる方にも満足していただけるよう努めています。その内容は――」

　ギルに説明できるのが嬉しいとでもいうように、どこか機嫌良さげな職員は要点をまとめて説明した。次のようなことだ。

　１．素材買取額が非加入者の５｜分《ぶ》増しになる。
　２．周辺地域の地図やその他の情報を無料で提供している。
　３．｜主《おも》な業務として仕事の斡旋をしていて路銀確保に役立つ。

　ギルと侍女たちは話の内容を心の内でさっと精査して、現実的にどのくらい役立つのか想像してみる。その中で気になったことをギルは問い掛ける。

「どれも役立ちそうだね。それで、冒険者ギルドは国内に広く展開してるの？」
「いえいえ、冒険者ギルドは各国本部や支部が世界中に存在しています――」

　そもそも冒険者ギルドの設立は約６００年前に｜遡《さかのぼ》るという。当時世界中で巻き起こった魔素氾濫の際に、「神託の感応石」が世界中に出現し、その神託に従って設立されたのが始まりなのだそうだ。

「神託の感応石からは今でも神託が｜齎《もたら》されています――」

　人類が魔物の脅威に立ち向かうという意志が一つになり、神託という形で｜齎《もたら》されると考えられているそうなのだが、その神託に基づいて冒険者ギルドは意思統一され世界中で連携しているらしい。
　未知の技術というか、力というか、そういったものに触れることができたギルたちは｜甚《いた》く感動した。

「これはぜひとも加入したいな……」
「｜凄《すご》いです！　きっと楽しいです！」
「未知なるものには興味がわきます」
「なんと、これはまさしく神秘……」

　実利的なこともさるものながら、世界に根を下ろす不思議の仲間入りをしたいということで、とにかく加入しようという流れになる。

「それではこちらの用紙に必要事項を記入して、加入料一人銅貨３枚の納付とともに提出してください」

　ギルたちは渡されたペンで一人ずつ順番に書き込んでいった。内容は名前の他にパーティ名と、「ギルドの規約に従います」という旨のサインだ。紙のほとんどは「各地域の法令を順守する」というような規約の文章になっている。
　パーティ名について、冒険者としての活動は仲間を集めて集団で行うことが一般的で、その集団を識別するのに簡単な名前を付けることになっているそうだ。ギルとしては何でもよかったのだが、侍女たちのことを考えて――

「『アルヴェの旅人』でどうだろう」

　――と、提案すると――

「故郷を思ってくださるのですねっ！」
「ギル様のお気遣いに感謝いたします」
「うふっ、アルヴェの旅人いいですね」

　ということになり満場一致で採択された。

　登録を受け付けた職員は｜暫《しば》らく席を外し、冒険者証のタグを持って戻ってくる。冒険者には資格試験で得られる「格」であるところの「クラス」が、Ａ～Ｆの６段階になって与えられ、加入したてのギルたちは最下位であるＦクラスの黄色いタグだ。
　冒険者は依頼者の依頼を斡旋してもらうことができるが、クラスによってそれが異なっているらしい。Ｆクラスでは依頼料が少額の簡単なものしか受けられないとのことだが、それ以外では特に変わりはないとのことだ。

　さて、登録も無事終了したギルたちは素材の売却へ向かおうということで、教えてもらった買い取り窓口への扉へ向かおうとした。そのとき数人の風体の悪い男たちが声を掛けてくる。

「ナめてんのか？」

　突然の困った｜質問《、、》に固まってしまいそうな体へ鞭打って、ギルは今にも飛び出しそうなエリアを手で制した。

（因縁を吹っ掛けるにももう少し何かあるだろう……）

　などと思ってしまう。現代地球では有無を言わさず殺し合いを始めるような裏の世界にいたギルからすれば、脅し文句などどれほどのものでもないのだが、異世界へ来たにせよ世間一般において絡まれた程度で殺してしまうわけにもいかない。いちいち付き合ってやらないといけないのだ。手っ取り早く済ませたいギルは、｜敢《あ》えて少し｜煽《あお》ってやる。

「常識的な尊重はするつもりだが？」
「てめぇ……、俺が教育してやる。付いてこい」

　この場で突然殴り掛かってくるような短慮でないことに内心ほっとしつつ、ギルたちが連れてこられたのは冒険者ギルド敷地内にある「｜虚影闘技場《ゴースト・アリーナ》」と呼ばれる施設だ。
　四方を階段状の観客席に囲まれた石畳の闘技場で、舞台の広さは１辺が１０メートルほどあった。屋根はなく明るい日光が差し込んでいて、客席にはまばらに観客が集まっている。観客席の一角にある出場者待機場所へギルたちが着いたときには、既に誰かが戦っているようだった。
　絡んできた男が冒険者ギルド職員の男に何事か話し掛けると、職員は困ったような表情をしつつギルの方をちらりと見る。その表情を見て取った職員は仕方ないといったふうにして｜頷《うなず》いた。そしてギルたちの方へやってくると話し始める。

「あまり気乗りはしないんだけどね、あんたがその気らしいから仕方ない」
「迷惑掛けて申し訳ない」

　絡まれた時点でギルに与えられた選択肢は限られていて、この事態を避けることができなかったとは言え、絡まれる｜隙《すき》を見せたのは自身の落ち度であるとギルは観念していた。職員の男は続ける。

「この｜虚影闘技場《ゴースト・アリーナ》は幻影同士が戦う魔法装置だ――」

　話によると、設置されたベッドに横たわって可動させると、その者と見た目も能力も変わらない幻影が闘技場に現れるのだそうだ。そして、その幻影が傷ついても死んでも本体に影響はないという。本気で戦う模擬戦ができるといった装置らしい。
　それを聞いたギルたちは、絡まれていることなど忘れて沸き立った。また新たな未知と遭遇したのだから仕方ない。レオナなど「私が代わりに」とでも言いたそうな表情をしている。そんなギルたちを、絡んできた男たちは気に入らなげにして｜睨《にら》み付けていた。

　さて、行われていた模擬戦が修旅するとギルと絡んだ男｜たち《、、》の番になる。職員に案内されてギルはベッドへ横たわり、勝手を知っている男たちも全員の５人が横たわった。
　職員が小さく｜鍵言《けんげん》を｜呟《つぶや》くと、ベッドに｜描《えが》かれた精緻な魔法陣が薄紅色の魔素光を発してギルたちを包み込む。ギルが楽しげに笑みを｜溢《こぼ》し、侍女たちは期待に胸を膨らませて覗き込んだ。
　そして投影を開始する魔法の｜鍵言《けんげん》が詠唱される。

「『｜魔力の成す存在の意味を投射せん《ガル・イグジステンズ・プロジェクティブ・ドライブ》！』」

　ベッドの魔素光が一際強く輝いてすぐにすっと消え、闘技場の６か所に薄紅色の魔素光が発生してその中からギルたちの姿が現れた。ギルは自身の手足を確かめるようにして、そしてすぐに戦闘に意識を切り替える。この世界に来てまともな対人戦はこれが初めてで、今の体が世間一般と比べてどの程度なのか確かめるいい機会だった。
　全員が円を描くように出現したことで、絡んできた男たちはすぐにギルを取り囲む。そしてそのうち声を掛けてきた男が、無駄に威張り散らすような歩き方で近づいてきた。不用意に近づいてくるのをギルが｜訝《いぶか》しんでいると、男は脅かすような声とともに剣を振るう。

「そらっ！」

　ギルは剣筋を見極めて最小限の動きで悠々と｜躱《かわ》した。男は少しイラッとしたように、今度はより速く斬り掛かる。

「くそがぁっ！」

　今度も悠々と｜躱《かわ》すギル。そこへ後ろから別の男が近寄ってきて無言で蹴りを放ち、前の男はそれに合わせて更に速く剣を振り抜く。

「おるぁっ！」

　後ろの気配が手に取るように分かるギルは、蹴りを｜躱《かわ》しながら後退して後ろの男の横をすり抜けて回避した。もう既に｜焦《じ》れてきた男は仲間たちに言い放つ。

「全員一斉に行くぞ！」

　ここまでの様子を見てやきもきいしていた男の仲間たちは素早く反応して動きだした。この程度なら５人同時でも｜躱《かわ》せそうな気のするギルだったが、「そればかりでは能がないか」と思い、少し手を変え、模擬戦終了へ一歩前の手を打つことにする。

「『｜巧御の万盾《オート・シールド》』」

　ギルが魔法の｜鍵言《けんげん》を詠唱すると、すわ反撃かと一瞬身構えた男たちだったが、何も起きないのを悟ると一気に間を詰めて凶刃を叩き込んできた。
　その瞬間、「｜巧御の万盾《オート・シールド》」に制御された「｜崩力の斥盾《リアクト・シールド》」がギルの周囲に５枚展開され、その橙色をした薄板が前方へ破裂するように飛び散って、男たちの｜剣戟《けんげき》に倍する斥力を発生する。

「ぐあっ！」「ぅぐぁっ！」「ぎゃぁっ！」「あがっ！」「ぅわぁっ！」

　振るった剣を岩に叩きつける以上の反撃に遭った男たちは、一斉に苦悶の悲鳴を上げながら体制を崩して吹き飛び、尻餅をついて倒れ込んだ。
　ギルはすかさず攻撃魔法の｜鍵言《けんげん》を詠唱する。

「『｜青い光弾《ブルー・ショット》！』」

　極めて重く固く生成した人の頭ほどもある魔素の弾体５つを、男たちが｜躱《かわ》せないだろうぎりぎりの遅い速度で射出した。迫る凶弾を可能な限り認識させて、少しでも死への恐怖を味わわせてやるのだ。多少は懲りてほしいという気持ちからである。

「うわっ！」「ひぃっ！」「あああっ！」「ぅああっ！」「ひぃあぁっ！」

　男たちは｜各々《おのおの》に恐慌の悲鳴を上げ、その直後に｜瑞々《みずみず》しい果実が破裂するような音を立てて頭部を爆散させた。｜脳漿《のうしょう》の｜飛沫《しぶき》が｜迸《ほとばし》り、破片になった脳が辺りに飛び散る。
　すると男たちの体から薄紅色の魔素光がふわっと発生して体ごと消え、出場者待機場で横たわっていた男たちに意識が戻った。

「「「「「あああああああああっ！」」」」」

　頭部が潰れるという臨死体験をした男たちは一斉に大声で｜喚《わめ》き、荒く息を｜吐《つ》きながら全身から大量の汗を流し始める。少しして、闘技場へ目を移す余裕が戻ったらしいが、そこにいたギルを目に留めると小さな悲鳴を漏らしながら、転げるようにベッドから降りて一目散に走って逃げていった。
　なかなか｜凄惨《せいさん》な幕切れだったが観客たちには慣れたもののようで、迷惑なごろつきに加えられた制裁に喝采が飛ぶ。｜虚影闘技場《ゴースト・アリーナ》の投影を解除する魔法の｜鍵言《けんげん》が発せられ、ギルの意識が出場者待機場のベッドへ戻ったことでこの模擬戦は終了した。
