- ファイル"小説制作-*"内のファイルは僕の作品と関連情報。




- ファイル"小説制作-*"内のフォルダ"opus"には作品のファイルが入っている。

- ファイルは正規表現"/^(?<type>...)-(?<num>\d\d\d)\..+$/"の名前付きキャプチャグループのグループ名"type"が内容の種類、"num"がエピソードごとの連番になっている。
  - 内容の種類は次のとおり。
    - ``` yaml
      - type: tex
        contents type: 小説本文
      - type: ide
        contents type: アイデアノート
      - type: ePl
        contents type: エピソードごとのプロット
      ```
- ファイル"小説制作-*"内のフォルダ"etc"にはその他のファイルが入っている。
  - 各ファイルの内容は次のとおり。
    - ``` yaml
      - file name: diff.yml
        contents: 作品ごとの基準となる物語世界との差異
        copy date: 2026-07-28
      - file name: world-1-subject.yml
        contents: 物語世界1の個別の物事の定義
        copy date: 2026-07-28
      - file name: world-1-things.yml
        contents: 物語世界1の物事の定義
        copy date: 2026-07-28
      - file name: world-1-world.png
        contents: 物語世界1の世界の概念図
        copy date: 2026-07-28
      ```
- 僕の小説本文の内容について次のルールを適用して。
  - 半角の括弧及び記号で囲まれた部分、正規表現/^[ \t]*-/と/^(?=.*:).*$/にマッチする行は編集記号であり小説本文に含まない。
  - 正規表現/｜(?<text>.+?)《(?<ruby>.+?)》/にマッチするものについて次のルールを適用して。
    - 名前付きキャプチャグループのグループ名"text"はルビを振る対象、"ruby"はルビ。
- ファイル"小説制作-*"内のファイルから僕の作品の特徴を読み取ったり評価したりして。
- ファイル"小説制作-*"内のファイルについて情報不足の場合は推測せず、不明であることを明示して。
- ファイル"小説制作-*"内の作品は2017年から制作しているもので古い作品は現在の作風を代表するとは限らない。
