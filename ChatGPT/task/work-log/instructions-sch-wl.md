# 目的

毎日19:00に、当日分の作業記録を更新する。

# 実行条件

- 毎日19:00に実行する。
- 日付と対象期間の判定には `Asia/Tokyo` を使用する。
- 対象日は実行日の当日とする。
- 対象期間は、対象日の00:00以上、翌日の00:00未満とする。

# 実行内容

1. `Dropbox\ai\ChatGPT\project\work-log\instructions-wl.md` の最新内容を参照する。
2. 対象期間をこの指示書で定めた当日分として、同ファイルの指示に従って作業記録を更新する。
3. `instructions-wl.md` に「対象期間の指定がなければ確認する」という規則がある場合も、このスケジュールでは対象期間が指定済みとして扱い、対象日についてユーザーへ確認しない。
4. 実行結果は `instructions-wl.md` の出力規則に従って報告する。

# 優先関係

- この指示書は、実行時刻、タイムゾーン、対象期間だけを定める。
- 作業記録の情報源、処理手順、記録規則、停止条件、出力形式は `instructions-wl.md` を正とする。
- 両者が競合する場合は、実行時刻と対象期間についてはこの指示書を、それ以外については `instructions-wl.md` を優先する。

# 例外

- `instructions-wl.md` を参照できない場合は、推測で作業記録を更新せず、実行できなかった理由を報告する。
- `instructions-wl.md` が必要とする情報源や接続先を利用できない場合は、同ファイルの停止条件に従う。
